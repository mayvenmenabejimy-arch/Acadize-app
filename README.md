# Acadize App Ecosystem

This repository contains the complete ecosystem for **Acadize** (https://acadize.com):

- **[`Acadize/`](./Acadize)**: Web application and backend API built with Express.js, TypeScript, React 18, and Drizzle ORM.
- **[`mobile/`](./mobile)**: Cross-platform mobile app built with React Native (Expo), TypeScript, Paymob Unified Checkout in-app WebView, and Meta event tracking.

---

## Getting Started

### Web Application & Backend
```bash
cd Acadize
npm install
npm run dev
```

### Mobile Application
```bash
cd mobile
npm install
npx expo start
```
